# Pastewell ASO copy pack

本目录只放文案与资产叙事，尚未写入 App Store Connect。所有结论与字符数均以当前仓库中的文本为准。

## 先改哪个

1. **Promotional text**：唯一不需要新版本、可在 ASC 直接替换的字段；确认 `promotional-text.md` 后先上线。

2. **1.1.1 元数据**：33 个 locale 的名称/副标题（现在只有 zh-Hans 本地化），Tier 1 的标题/副标题/关键词/描述前三段。

3. **1.1.1 截图**：5 张，Tier 1 八种语言本地化；其余语言回退英文。

4. **1.1.1 评分提示**：在成功使用后请求系统评分（代码改动，不在本目录）。

5. **外部曝光**：等 1.1.1 上线后再做，避免把流量导向低转化页面。

## 验证方式

- 字符数：生成时逐字段校验；标题/副标题 ≤30，关键词 ≤100，促销 ≤170，描述 ≤4000，headline ≤40。

- 关键词去重：对每个 Tier 1/2 locale 检查关键词是否与标题/副标题存在完整词或子串重叠；结果见本目录生成记录。

- 禁用表述：对 `docs/aso/` 执行词表检查，7 个禁用词均为 0 命中；词表不在文档中复写，避免文档自身命中。

## 哪些等 1.1.1

标题、副标题、关键词、描述与截图都必须随 1.1.1 提交；Promotional Text 可先单独上线。

## 风险与待确认

- 所有非中英文本均为机器翻译后的人工调整，未由母语者逐条校对；Tier 1 的建议至少让母语者过一遍。

- he 的剪贴板术语、ms 的“历史”用词、th 的“效率”与“生产力”区分、ar 的标点方向，建议重点复核。

- 商店版选中条目后只把内容放回剪贴板，用户需自己按 ⌘V；文案不得写成选中即粘贴。
