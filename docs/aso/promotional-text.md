# Promotional text (34 locales)

Apple 的 Promotional Text 上限 170 字符，可在不提交新版本的情况下修改。以下文本尚未写入 ASC；确认后再上线。

`⌘⇧V` 为三个字符。字符数按 Unicode code point 统计。

## 给用户过目的两份

### English (en-US)
```text
Now in 34 languages. Copy once, press Cmd+Shift+V, and find it again in a keystroke. Private by design: no account, no network, history stays on your Mac.
```

### 简体中文 (zh-Hans)
```text
现已支持 34 种语言。复制一次，按 Cmd+Shift+V，一次按键就能找回。隐私优先：无需账号、不联网，历史只保存在你的 Mac 上。
```

## 待确认

以下语言的措辞为机器翻译后的人工调整，建议母语者复核：he、ms、th、ar-SA、hi、vi、uk、el、hr、ro、ca。其余语言由常见 IT 用语写成，风险较低。

### 具体待确认点

- he：`היסטוריה` 是通用“历史”，剪贴板语境可考虑 `היסטוריית לוח הגזירים`；请母语者定夺。

- ms：`sejarah` 在马来语里更常指“历史事件”，剪贴板历史建议确认是否用 `sejarah papan keratan`。

- ar-SA：RTL 标点与“السجل”是否自然，请母语者确认。

- th：`ประวัติ` 与 `ประวัติการคัดลอก` 的取舍待确认。

- ro：标题使用英文借词 `Clipboard`，罗马尼亚语日常更常说 `clipboard`，但请确认。

- pt-PT：欧洲葡语用 `Já em 34 idiomas` 是否自然，请母语者确认。
